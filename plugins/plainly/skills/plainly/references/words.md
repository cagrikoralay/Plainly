# Plain word swaps

Our own list of common swaps. The checker script reads the table below, so keep the
format: `| avoid | use instead |`. Lowercase. One row per word or phrase.

A swap is a suggestion, not a law. Keep a word when it is the precise technical term
(for example, "terminate" for a process signal in Unix).

## Phrasal verbs and jargon

Phrasal verbs and slang confuse non-native readers and translation tools.

| avoid | use instead |
|---|---|
| carry out | do |
| figure out | find, learn |
| come up with | make, think of |
| look into | examine |
| point out | show, say |
| get rid of | remove, delete |
| nuke | delete |
| spin up | start, create |
| kick off | start |
| circle back | return to |
