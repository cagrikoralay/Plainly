# Plainly

Add the catalog once. Then install only the
plugins you want.

```text
/plugin marketplace add cagrikoralay/Plainly
/plugin install plainly@cagrikoralay
```

## Skills for claude.ai and Claude Desktop

Each plugin's skill is also available as a zip in [downloads/](downloads/). Upload the zip as a
skill in claude.ai or Claude Desktop.

## Plugins

| Plugin | What it does | Install |
|---|---|---|
| [Plainly](plugins/plainly/) | Explain, rewrite, or check text in plain, short English. Loosely inspired by the controlled English of aircraft maintenance manuals. | `/plugin install plainly@cagrikoralay` |

## Updates

Run `/plugin marketplace update cagrikoralay` to get new versions.
